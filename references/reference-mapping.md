# 参考论文：核验图号，再说明如何改画

## 来源选择

优先顺序：用户提供的论文/图片 → 已核验的项目参考 → 公开论文原文。

论文图未提供内容时，使用可用的浏览或文档工具查看原文。不能凭记忆编图号，也不能把搜索摘要当作已看过图片。无法访问时注明“图号/画面未核验”，继续完成已知的模型结构。

默认选择正式会议、期刊、作者公开论文、OpenReview、PMLR、CVF 或 arXiv 等可追溯来源；区分正式发表与预印本。沿用 CCFA 的默认来源偏好，不把 MDPI 来源列为自动推荐；用户明确指定的材料可按其要求处理并标明来源。

不要把未公开的方法全文、用户项目路径或实验记录粘贴到外部检索。使用公开机制关键词。若需要发送未公开材料给外部图像/设计服务，遵守宿主授权规则，先确认现有授权是否覆盖具体内容。

## 必须交付的参考映射

| 自有模块/局部 | 论文、年份、版本、直达链接 | 已核验图号 | 借鉴点 | 改绘动作 | 不能照搬的内容 |
|---|---|---|---|---|---|

“可借鉴”必须具体，例如：

- 将多路输入放在同一侧，按照信息时点分行。
- 用切片堆叠表达成员维，分别引出均值和标准差。
- 将主效应曲线放在加性求和之前。
- 用旁路连接基准预测，并在实际相加处画加法器。

“改绘动作”要说明替换后的输入、输出、维度、操作与分支。只列论文标题或说“参考其风格”不算完成。

## 引用与视觉借鉴的边界

- 图形参考证明某种表达方式可用，不证明本方法的新颖性或性能。
- 借鉴结构表达、输入展示和连接语法；不直接复制论文的独特构图、图标、图像和结果曲线。
- 保留短引用记录。用户只要图时，把详细链接和改绘说明放在 figure-notes，而非塞进图内。
- 论文版本变化可能导致图号变化，记录具体 PDF 版本或访问日期。
- 不能把文献中的不存在于本模型的 ICL、选择器、位置编码、蒸馏或辅助任务移植进图中。

## 用户问“是否独创”时

1. 按机制检索，而不仅按候选模块名字检索。
2. 找最接近的来源并检查方法正文/公式。
3. 分开列出：已有机制、当前实现的差异、尚未验证的贡献。
4. 完整组合未被搜到，只能说“本次检索未发现完全相同组合”，不能说“全球首创”。
5. 不通过换名字回避已有工作。对高度相关论文，即使其标题或应用领域不同，也说明重合处。
6. 不因用户问创新性而擅自改图或改模型。
