# 数据、张量与数学连接的视觉语法

## 1. 数据不是维度文字框

| 对象 | 默认视觉表达 | 应标内容 |
|---|---|---|
| 表格输入 | 小表格或分组列条 | 行/列含义、特征组、`[B,F]` |
| 特征选择 | 原列、分数/掩码、保留列之间的对应 | mask/索引形状、输出特征数；仅当模型实际选择 |
| 按时点分组 | 不同颜色的列组与可用时点 | 各组列数、Concat 轴；不称学习式选择 |
| 特征提取 | 基函数曲线、卷积/投影前后表征 | 转换前后形状及操作 |
| token 序列 | token 条、CLS 与特征 token 的区分 | token 数、通道维、拼接方向 |
| 矩阵 | 网格与轴标签 | 两个轴的含义和形状 |
| 三维张量 | 网格切片加浅堆叠 | 正面两轴、堆叠轴、完整形状 |
| 集成预测 | 成员切片或少量并行成员加省略号 | `[K,B,C]`、mean/std 沿哪个轴 |
| 门控 | 向量/列向量与权重分叉 | 权重形状、广播方向、互补权重来源 |
| 预测 | 小矩阵/向量与任务标签 | logit、概率、类别或连续值；实际单位/变换 |

一个二维小网格画四行只是示意，不能让人误认为 batch size 等于 4。通道数很大时省略单元格，保留轴标签。

结构示意曲线不要标实验数值或声称是实际特征效应。真实曲线必须来自可追溯结果。使用色块表示特征组时，全图保持语义一致。

## 2. 运算符约定

默认采用用户偏好的计算图图例，见 `assets/operator-legend.svg`：

| 图形 | 本 Skill 图例语义 | 正文公式 | 形状要求 |
|---|---|---|---|
| 圆内完整十字 | 逐元素加法 | `A + B` | 同形状，或明确广播 |
| 圆内斜叉 | 矩阵乘法 | `AB` 或 `A @ B` | 收缩维一致，批次轴兼容 |
| 圆内实心点 | 逐元素乘法 / Hadamard 积 | `A ⊙ B` | 同形状，或明确广播 |
| `Concat` 矩形 | 拼接 | `Concat(A,B; axis=t)` | 非拼接轴一致 |
| `Σ` / `Mean` / `Std` | 聚合 | 标明下标/轴 | 输出轴正确减少或保留 |
| `Scale γ` | 标量缩放 | `γA` | 张量形状不变 |
| `Softmax` | 归一化 | 标明 axis | 不误当作改变类别维数 |

圆内斜叉也可能在别的数学语境表示 Kronecker 积；圆内十字可能表示直和。必须给图例，不能把绘图约定声称为跨领域统一标准。用户或目标领域已有约定时优先使用其约定。

矩阵点乘在本项目默认指 Hadamard 逐元素乘法。若源方法实际做向量内积 `aᵀb`，应标 `Dot/Inner product` 并显示标量输出，不使用会暗示同形状结果的表达。

## 3. 连接拓扑

- `A → 运算节点 ← B`，再由节点连到结果。不要先把两条输入线合并，再接算子，让人无法区分操作数。
- 权重/参数可以从上方或下方接入；不要让标签压在输入线上。
- 纯交叉线不表示合并；尽量绕开，确需交叉可采用桥接。真正分叉处保持明显连续，必要时加实心连接点。
- 连接点的小实心点与带外圈的 Hadamard 操作符必须有明显尺寸和边界区别。
- 图中发生加法、乘法、拼接或聚合的位置均可定位；不为未发生的操作添加装饰性符号。
- 实线用于推理数据流；虚线默认用于训练监督或训练统计拟合。参数/控制边若需独立样式，增加图例。

## 4. 维度与轴

- 统一定义 `B`（样本批次）、`F`（特征）、`T`（序列/token）、`D`（通道）、`K`（成员）、`C`（任务通道）。根据领域调整符号，避免同符号多义。
- 标注实际 dtype；不凭视觉默认都是 float32。dtype 未知可省略并在笔记中说明，shape 仍可用符号。
- `[B,F,D]` 与 `[K,B,C]` 的张量堆叠轴不同，不能仅替换标题而保留错误轴标。
- 分类两个 logits `[B,2]`、二值标签 `[B]` 和概率 `[B,2]` 是不同对象；`Softmax/Argmax` 只有实际绘制该阶段时才加入。
- 对三维运算明确批量矩阵乘法或收缩公式，例如 `E_j[B,D] = Φ_j[B,R] G_j[R,D]`。不要把任意两个三维张量标成普通二维乘法。
- 门控 `[B,1]` 乘输出 `[B,C]`，说明沿 `C` 广播；不能画成矩阵乘法。
- 区分 reshape、transpose、flatten、pool 和投影：前几者不学习新特征，投影改变特征空间；reshape 要保持元素数。

## 5. 论文阅读尺度

构图围绕计算关系，控制框中文字长度。用户在 PPT 中手工画论文图，不等于需要演示文稿式的大标题、阶段卡片和装饰图标。

在预期单栏/双栏尺寸下检查文字与箭头，而不只看超大画布。模块配色用于辅助定位；去掉颜色后仍应能顺着连线读懂。
